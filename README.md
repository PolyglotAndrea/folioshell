# folioshell

> A terminal-style personal blog & portfolio for **B. Andrea Horvath** — Senior AI Full-Stack Architect & Founder of [Cognix.one](https://cognix.one).

Live demo: open `index.html` in any browser — no build step required.

## Features

- 🖥️ Full-screen macOS-style terminal window with traffic light buttons
- ⌨️ Interactive CLI — type real commands to navigate the portfolio
- 🎨 [Catppuccin Mocha](https://github.com/catppuccin/catppuccin) colour scheme with ambient glow blobs
- ✨ Animated skill bars, fade-in lines, blinking block cursor
- 🔼 Command history (`↑ ↓`) and `Tab` completion
- 📱 Zero dependencies — pure HTML / CSS / JS

## Commands

| Command | Description |
|---------|-------------|
| `me` | Full profile & executive summary |
| `whoami` | One-liner intro |
| `skills` | Skill matrix with animated bars |
| `projects` | Key projects |
| `interests` | Technical interests |
| `contact` | Links & contact info |
| `ls` | List all "files" |
| `cat <file>` | Read a file |
| `banner` | ASCII art banner |
| `clear` | Clear screen |
| `help` | Show all commands |

## Customisation

All personal data lives in the `CONFIG` object at the top of `main.js`. Edit that block — no other changes needed.
